# KHI Media Website

A premium digital agency website built with modern web technologies and exceptional user experience.

## 🚀 Features

- **Responsive Design**: Fully responsive across desktop, tablet, and mobile devices
- **Dark/Light Theme**: Seamless theme switching with localStorage persistence
- **Premium Animations**: Smooth scroll reveals, hover effects, and micro-interactions
- **Modern Typography**: Clean, professional typography with proper hierarchy
- **Optimized Performance**: GPU-accelerated animations and efficient code
- **SEO Ready**: Semantic HTML5 structure and meta tags
- **Cross-browser Compatible**: Works on all modern browsers

## 🛠️ Technologies Used

- **HTML5**: Semantic markup with accessibility in mind
- **CSS3**: Modern CSS with custom properties and animations
- **Vanilla JavaScript**: No frameworks, pure JS for optimal performance
- **Responsive Design**: Mobile-first approach with media queries

## 🎨 Design System

- **Primary**: Blue accent (#3B82F6)

## 🚀 Getting Started

### Prerequisites
- Modern web browser
- Local development server (optional)

### Local Development
1. Clone the repository
2. Open `index.html` in your browser
3. No build process required - it's vanilla HTML/CSS/JS

### Customization
- Edit `index.css` for styling changes
- Modify `index.js` for behavior updates
- Update logo files in root directory
- Adjust theme colors in CSS variables

## 🔧 Configuration

### Theme Variables
All colors and spacing are controlled via CSS custom properties in `:root` selector. Easy to customize for different brand requirements.

### Logo Management
- **Light Theme**: Uses `lightlogo.png`
- **Dark Theme**: Uses `darklogo.png`
- **Automatic**: Theme preference saved to localStorage
